# imgc · MVP 设计方案

> **imgc** 是一个本地小工具，专门解决"图片传不进 DSH"的问题：把截图或图片一键压到 DSH 能接受的大小，直接粘进对话框。

---

## 1. 🎯 工具是什么

一句话：**截图 → 按快捷键 → 点一下 → 回 DSH 粘贴**。

它只做三件事：

| 图标 | 功能               | 一句话说明                                             |
| ---- | ------------------ | ------------------------------------------------------ |
| ⚡   | **快压截图** | 把剪贴板里刚截的图压好，再放回剪贴板，直接粘进 DSH     |
| 📦   | **批量压缩** | 一堆图片一次压好，统一存到指定文件夹                   |
| 🎛️ | **参数配置** | 常用压缩档位存成预设，日常免调参；需要时可临时精细设置 |

**两个入口**：图形界面（快捷键召唤）、终端命令行。两个入口功能完全一致。

---

## 2. 🚀 三个核心功能

### 2.1 ⚡ 快压截图（剪贴板 → 剪贴板）

**做什么**：读取剪贴板里的图片（只认图片，不处理"复制的文件"），压缩到符合 DSH 要求，然后把压缩结果放回剪贴板。你切到 DSH 输入框按 `Ctrl+V` 就能粘进去。

**图形界面**

1. 用 `Win + Shift + S` 截图（图自动进剪贴板）
2. 按快捷键唤出 imgc 窗口
3. 点 **「⚡ 快压截图」**（窗口打开时该按钮已选中，直接按回车也行）
4. 切回 DSH，`Ctrl+V` 粘贴 → 完成

压缩完成后窗口显示一行结果：

```
原图  3840×2160  3.21 MB
新图  2000×1125  412 KB   ✅ 已复制到剪贴板（省 87%）
```

**命令行**

```bash
imgc clip                 # 压缩剪贴板图片 → 写回剪贴板
```

命令执行后打印同样的对比信息，方便确认。

**出错时怎么提示**（界面弹红条，命令行打印并返回非零退出码）

| 情况                      | 提示                                                                 |
| ------------------------- | -------------------------------------------------------------------- |
| 剪贴板里没有图片          | ⚠️ 剪贴板里没有图片，请先截图或复制一张图片                          |
| 剪贴板内容是文件而非图片  | ⚠️ 剪贴板里是文件，快压截图只处理图片，请改用「📦 批量压缩」         |
| 图片无法读取（损坏/不支持） | ⚠️ 无法读取该图片（HEIC 等格式需先转为 PNG/JPG），请检查后重试        |
| 压缩后仍超出 DSH 限制     | ⚠️ 已压到极限仍超出 {哪一项}，建议改用 tiny 预设                     |
| 写回剪贴板失败            | ⚠️ 写回剪贴板失败，请重试；或改用「📦 批量压缩」把图存到文件夹后拖入 |

> 快压截图**只做一件事：剪贴板进、剪贴板出**。它不落盘、不做兜底保存——出问题就明确报错，让你重试或改用批量压缩，避免出现"文件到底存哪了"的困惑。

### 2.2 📦 批量压缩到指定文件夹

**做什么**：一次处理多张图片，全部压缩后统一保存到指定文件夹。适合整理一批素材、或者一次要给我看很多张图。

**图形界面**

1. 点 **「📦 批量压缩」**
2. 选择图片（支持多选，可混选不同格式）
3. 选择输出文件夹（**默认显示为默认目录**，并记住上次选择过的目录）
4. 选择压缩预设模式（用默认预设，或打开预设列表选一个具体的预设），**或**展开 **「单次参数设置」**（只在这里提供精细参数，见 §2.3）
5. 点「开始压缩」

**操作提示**（界面上的引导文案）

- 选择文件时：`已选 8 张 · 合计 24.6 MB`
- 处理过程中：`正在压缩 3/8 …`
- 完成后汇总：

```
✅ 成功 7 张    ❌ 失败 1 张
原图合计 24.6 MB  →  压缩后 3.8 MB（省 85%）
输出目录：C:\Users\hp\Desktop\zzyFile\myProjects\image_compress\imgc\   [打开文件夹]
失败项：c.png — 文件已损坏，无法读取
```

**命令行**

```bash
imgc batch a.png b.jpg D:\pics\*.png --out D:\imgc   # 混合写法，输出到 D:\imgc
imgc batch *.jpg                                     # 不写 --out，输出到默认目录
imgc batch d.png --preset tiny --long-side 1280      # 预设铺底 + 单次参数覆盖
```

> ⚠️ **通配符注意**：Windows 的 cmd 与 PowerShell **都不会**帮程序展开 `*`，会把 `*.jpg` 原样传给程序。因此 **imgc 内部自己展开通配符**（自己扫描目录做匹配），这样上面这种写法才能直接用。

**📁 默认输出目录**：本项目目录下的 `imgc/`（即 `...\image_compress\imgc\`）。目录不存在时自动创建；`--out` 或界面上的选择可临时改变它，并会记住上次用过的目录。

**📥 输入格式**：能读的一律**自动转换**成 PNG/JPG/WebP（如 BMP、AVIF、TIFF）；读不了的（如 HEIC 缺组件、文件损坏）明确报错并指出是哪个文件。

**输出文件命名**：在原文件名基础上依次追加 `预设` `尺寸` `体积` `同名序号`，切片结果再追加切片号。

```
screenshot-dsh-2000x1125-412KB-1.webp          # 整图压缩的第 1 个结果
screenshot-dsh-1080x1800-380KB-1-CUT1.webp     # 长截图切片的第 1 片
screenshot-dsh-1080x1800-372KB-1-CUT2.webp     # 长截图切片的第 2 片
```

- `-1`：**同名 + 同格式**的压缩结果中的第 1 个（同条件再压一次就是 `-2`），保证绝不覆盖已有文件
- `-CUT1`：该压缩结果的第 1 个切片（共几片，完成汇总里会说明）

**长截图特殊处理**：像 1080×8000 这种整页截图，整体缩放会糊到看不清字。用 `long` 预设时按下面的规则处理：

> 📐 **切片模式规则**：只有**宽度**受 2000px 限制（超了就按比例缩宽度）；**高度不设限**，由切片高度（默认 1800px）切成多片，相邻两片重叠 60px，避免把一行文字切两半。

一次粘 5–8 片进 DSH 完全没问题（DSH 允许一条消息带 20 张图）。

### 2.3 🎛️ 参数预设与配置

**做什么**：把常用压缩档位存成预设。日常直接用默认预设，一键就压；需要精细控制时（批量压缩中）可以临时调单项参数。

**图形界面**：点 **「🎛️ 设置参数」** → 选择/编辑/创建预设、设定默认预设、保存。

**内置预设**（可自由增删改）

| 预设                  | 长边 / 宽度 | 目标体积  | 适用场景                                |
| --------------------- | ----------- | --------- | --------------------------------------- |
| **dsh**（默认） | 2000        | ≤ 800 KB | 通用截图，一个会话能留住约 19 张图      |
| dsh-big               | 2000        | ≤ 3 MB   | 要看清细节的设计稿、报错截图            |
| text                  | 2000        | ≤ 500 KB | 文字/代码截图（比 JPEG 清晰得多且更小） |
| tiny                  | 1280        | ≤ 200 KB | 一次传很多张，只看个大概                |
| photo                 | 2000        | ≤ 1 MB   | 照片                                    |
| long                  | 宽度 2000   | ≤ 800 KB | 长截图，自动纵向切片（高度不限）        |

**单次精细参数**（图形界面里只在"批量压缩"中展开；命令行用 `batch` 的参数）

| 参数            | 说明                            |
| --------------- | ------------------------------- |
| 长边上限        | 默认 2000，超过 DSH 会被拒      |
| 目标体积        | 填 0 表示不限体积               |
| 输出格式        | 自动 / PNG / JPEG / WebP        |
| 质量            | 40–95，默认 82（PNG 无需此项） |
| 切片高度 / 重叠 | 长截图用                        |
| 透明底色        | 透明图转 JPEG 时的填充色        |
| 灰度            | 文字截图可再省约 30%            |

> ⚙️ **优先级规则**：**预设先铺底，单次参数逐项覆盖**。界面上改过单次参数后，参数框会实时显示覆盖后的最终值，不会出现"我改了参数却没生效"的情况。

> 🔒 **预设保护**：当前**默认预设不可删除**（要删必须先切换默认预设）；若预设列表意外为空，启动时自动恢复内置预设，保证「⚡ 快压截图」永远有参数可用。

**命令行**

```bash
imgc preset list                    # 查看所有预设
imgc preset set dsh                 # 把 dsh 设为默认预设
imgc preset edit text --target 400kb	# 编辑 text 预设的参数
imgc preset delete dsh-big			# 删除 dsh-big 预设（默认预设不允许删除）
imgc preset new dsh-small			# 新建 dsh-small 预设，接着会要求输入各个参数的数值
```

## 附录 📏 默认参数的由来

默认值不是拍脑袋定的，是按 DSH 的实际限制倒推的：

| DSH 限制                   | 数值                     | 对工具的影响                                                   |
| -------------------------- | ------------------------ | -------------------------------------------------------------- |
| **单边最大像素**     | **2000 px**        | 👉 硬墙，改配置也绕不过，所以默认长边就定 2000，缩放是默认动作 |
| 单张图片体积               | 3.5 MB（当前生效 20 MB） | 👉 取保守值，即使将来限制收紧也不会失效                        |
| 一次请求图片总量（编码后） | 20 MB                    | 👉 相当于真实图片总量约 15 MB，且是**整段对话累计**      |
| 允许格式                   | PNG / JPEG / WebP / GIF  | 👉 输出只用前三种；输入的其他格式能读就自动转换                |
| 每张平均预算               | ≈ 800 KB                 | 👉 按此算一个会话能留住约 19 张图，老图不会被悄悄挤掉          |

> **关于最后一行**：DSH 一次请求里所有图片的体积总和有上限，超了它不会报错，而是**把最老的图片悄悄替换成一行文字**（表现为"我好像忘了前面那张图"）。所以把单张压在 800KB 以内，是让图片在长对话里"活得久"的关键。
